PROJECT KHOI HOP 3D

Cac tep:
- index.html: giao dien
- style.css: dinh dang giao dien
- app.js: xu ly ve khoi hop, nut dieu khien va thao tac chuot

Cach chay:
1. Giai nen ZIP vao mot thu muc.
2. Mo thu muc do trong Visual Studio Code (File > Open Folder).
3. Neu da cai Live Server: nhan chuot phai vao index.html > Open with Live Server.
4. Hoac co the mo truc tiep index.html bang Chrome/Edge vi day la HTML + CSS + JavaScript thuần.

Luu y:
- Ba tep phai nam cung mot thu muc.
- Ban app.js trong goi nay da sua selectedAxis, rotateAxis va drag thanh let,
  vi cac bien nay duoc cap nhat trong luc thao tac.
- Neu van gap loi, mo Developer Tools > Console va gui dong loi do.
